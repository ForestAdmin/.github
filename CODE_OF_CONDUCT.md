# Code of conduct

All Forest repositories follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome people of every background and experience level, and focus on what is best for the community. Harassment, insults and personal attacks are not tolerated.

## Scope

This code applies in every Forest space on GitHub (issues, pull requests, reviews) and whenever someone represents the Forest community.

## Reporting

If you see or experience behavior that breaks this code, contact the Forest team at [support@forestadmin.com](mailto:support@forestadmin.com). Every report is reviewed and handled confidentially.

The Forest team may remove, edit or reject comments, commits, code and other contributions that break this code, and may temporarily or permanently ban a participant, as described in the Contributor Covenant's enforcement guidelines.
