# Getting help with Forest

Pick the channel that matches your question.

| You want to | Go to |
|---|---|
| Set up or use Forest | [Documentation](https://docs.forest.app/get-started/quickstart) |
| Report a bug in an agent or a package | An issue in the repository concerned, using its template |
| Get help from the Forest team: onboarding, deployment, workflows, integrations, production issues | [Support request form](https://forest.app/forms/support) |
| Report a security vulnerability | Our [security policy](./SECURITY.md). Never a public issue. |

Issues are for bugs in the code of the repository. Questions about how to use Forest get faster answers from the documentation or the support team.
